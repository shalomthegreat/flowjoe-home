Before you open it

First launch, a few quick steps.

Opening FlowJoe the first time

This alpha is not yet verified by Apple or Microsoft, so Mac and Windows may show a first-open warning. Signed builds arrive before the public launch. Step by step: Install FlowJoe.

  1. MacDownload the .dmg for your Mac’s processor. Quit any older FlowJoe, open the .dmg and drag FlowJoe into Applications; choose Replace if asked. Eject the installer and open FlowJoe from Applications. If macOS says it cannot verify FlowJoe, dismiss the warning, then go to System Settings → Privacy & Security and click Open Anyway. Confirm with your Mac password and click Open if asked. If an older download says “damaged”, download the current installer again from this page and replace the old copy.
  2. WindowsRun the downloaded .exe. If you see “Windows protected your PC”, click More info, then Run anyway, and follow the installer. FlowJoe installs for your account without an administrator password; open it from the Start menu. If your work or school computer blocks the installer without a Run anyway option, ask its administrator to allow FlowJoe.
  3. LinuxDebian / Ubuntu: open the .deb in your software installer, or run sudo apt install ./flowjoe_*_amd64.deb from the download folder; use the exact filename if that folder contains several versions. Open FlowJoe from your applications menu. AppImage: from the download folder, run chmod +x FlowJoe-*.AppImage, then double-click the file. If it reports a FUSE error, use the .deb on Debian / Ubuntu or follow the AppImage FUSE instructions for your distribution.
